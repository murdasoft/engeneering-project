# InspectAI Crack Segmentation Training Space

This Space trains a YOLOv8-seg model on public crack datasets:

- Ultralytics Crack-Seg (4,029 images)
- IBM Cracks in the Foundation (CIF) dataset

Training starts automatically on Space startup. The final `best.pt` is uploaded to:
https://huggingface.co/alllxndr/inspectai-crack-seg

View the live log at `https://huggingface.co/spaces/alllxndr/inspectai-train` under **Files & versions > train.log**.
